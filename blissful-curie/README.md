# 속속 (SOCSOC) - 화장품 처방 포털 & 제형 개발 워크벤치

화장품 처방 데이터베이스 및 연구원용 배합비 계산기 웹 플랫폼입니다.

## 주요 기능
- **가이드 처방 보관함**: Skin Care, Sun Care, Body, Hair, Make-up 5개 카테고리별 정예 처방 및 원문 데이터 제공
- **독립 제형 개발 계산기**: 소수점 둘째 자리(0.00%) 정밀 계산, 정제수(ad 100) 자동 밸런싱, 비커 배치 중량(g) 환산
- **반응형 웹 UI**: Tailwind CSS 기반의 모바일/태블릿/PC 최적화 대시보드

## 파일 구조
- `index.html`: 메인 대시보드 및 워크벤치 애플리케이션
- `recipes_data.js`: 처방 데이터셋
- `data/`: 원본 및 정제 JSON 데이터 파일
- `_redirects`: SPA 라우팅 및 호스팅 리다이렉트 설정
- `robots.txt`: 검색엔진 크롤링 최적화 설정
